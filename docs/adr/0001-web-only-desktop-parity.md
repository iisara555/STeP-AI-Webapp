# ยกระดับความสามารถผ่านเว็บโดยไม่ติดตั้งตัวช่วยบนเครื่องพนักงาน

วันที่ 24 ตุลาคม 2569 ผู้ใช้เลือกให้ Desktop parity ใช้งานผ่านเว็บอย่างเดียว แทนการติดตั้ง
companion เพื่อเข้าถึงเครื่องพนักงาน โดยคง Webapp เป็น centralized PWA และไม่แก้ checkout Desktop
ความสามารถ browser/MCP/process ที่จำเป็นจึงต้องออกแบบการทำงานฝั่งเซิร์ฟเวอร์และการแยกข้อมูล/สิทธิ์
ก่อนนำมาใช้; ไม่อ้างว่าสามารถใช้ไฟล์ บัญชี หรือโปรแกรมในเครื่องพนักงานได้โดยอัตโนมัติ

ทางเลือกนี้ลดภาระติดตั้งบนเครื่องพนักงาน แลกกับการต้องจัดการ runtime และทรัพยากรของเครื่องมือส่วนกลาง
การตัดสินใจนี้ยังไม่ได้เลือกรูปแบบ sandbox, host, ผู้ให้บริการ, ค่าใช้จ่าย หรืออนุญาตให้ provision/deploy
